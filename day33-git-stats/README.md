# 📊 Git Stats Analyzer

**Day 33/100 - Visualize your git history**

## What It Does

- Total commits
- Contributor rankings
- Commits by day of week
- Commit type breakdown
- Longest streak
- Recent activity

## Usage
```bash
cd any-git-repo
python3 /path/to/git_stats.py
```
