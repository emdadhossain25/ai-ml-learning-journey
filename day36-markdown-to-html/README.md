# 📝 Markdown to HTML Converter

**Day 36/100 - Turn markdown into beautiful web pages**

## Usage
```bash
python3 md2html.py input.md
python3 md2html.py input.md output.html
python3 md2html.py input.md --style=dark
```

## Styles

- `default` - GitHub-like (clean, professional)
- `dark` - Dark theme (easy on eyes)
- `minimal` - Minimalist serif (elegant)

## Supports

✅ Headers (H1-H6)
✅ Bold, italic, bold+italic
✅ Inline code & code blocks
✅ Links & images
✅ Ordered & unordered lists
✅ Blockquotes
✅ Horizontal rules

## Example

**Input (markdown):**
```markdown
# Hello World

This is **bold** and *italic*.

- Item 1
- Item 2
```

**Output:** Beautiful HTML page! 🌐

## Use Cases

- Convert README to webpage
- Turn notes into blog posts
- Create documentation sites
- Share formatted content
