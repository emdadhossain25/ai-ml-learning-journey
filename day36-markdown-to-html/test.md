# Markdown to HTML Converter

Convert your **markdown** files to beautiful *HTML* pages!

## Features

- Headers (H1-H6)
- **Bold** and *italic* text
- `Inline code`
- Links and images
- Lists (ordered and unordered)
- Code blocks
- Blockquotes

## Example Code
```python
def hello():
    print("Hello, World!")
```

## Lists

**Unordered:**
- Item 1
- Item 2
- Item 3

**Ordered:**
1. First
2. Second
3. Third
