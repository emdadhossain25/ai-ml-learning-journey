## Key Learnings

### React Native ≈ Android (Different Notation)

**Android:**
```kotlin
val counter = MutableLiveData<Int>(0)
textView.text = counter.value.toString()
```

**React Native:**
```javascript
const [counter, setCounter] = useState(0);
<Text>{counter}</Text>
```

**Same concept, different syntax!** 🎯
