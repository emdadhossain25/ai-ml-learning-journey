# ⏱️ Pomodoro Timer

**Day 34/100 - Terminal focus timer**

## Usage

**Pomodoro Mode:**
```bash
python3 pomodoro.py
# 25 min work, 5 min break, repeat
```

**Quick Timer:**
```bash
python3 pomodoro.py 10
# 10 minute countdown
```

## Features

✅ Visual countdown in terminal
✅ Progress bar
✅ macOS notifications
✅ Long breaks every 4 sessions
✅ Session tracking
